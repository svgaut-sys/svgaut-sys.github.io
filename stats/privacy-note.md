# Privacy & credits

## Privacy

JAI Profile Studio is a fully static site — **it has no backend and collects nothing**.

- Your theme settings are saved only in your own browser (localStorage) so you don't lose work between visits. Nothing is ever transmitted or stored anywhere else.
- Theme JSON files you Save/Load and the CSS you export live only on your computer.
- The only external requests the page makes are to **Google Fonts**, to render font previews. Google's privacy policy applies to those font requests.
- This project is not affiliated with JanitorAI.
